# GenC Cohort Leaderboard 🏆

A fair, momentum-driven creator leaderboard for the GenC community.

Unlike traditional leaderboards that celebrate who already has the largest audience, the GenC Leaderboard rewards **posting consistency, creative breakthroughs (outliers), and view acceleration (slope)**.

---

## Key Features

- 📈 **2nd-Order Momentum Metrics:** Ranks creators by view acceleration slope across their recent reels/videos rather than absolute vanity follower numbers.
- 🎯 **Adaptive Consistency:** Measures pacing discipline against each creator's committed posting cadence (Daily, 3-4x/week, Weekly).
- ⚡ **Breakout Detection:** Automatically identifies outlier videos ($>3\times$ personal baseline) so the cohort can study winning hooks and structures.
- 🏰 **The House Cup:** Aggregates member scores into balanced House teams with weekly crown announcements.
- ⚙️ **Configurable Admin Settings:** Thresholds, point multipliers, and evaluation windows are adjustable live from the UI.
- 🤖 **Automated Sync & Discord Broadcasts:** Refreshes every 6–12 hours and sends rich updates directly to Discord.
- ☁️ **Cloud Native & Portable:** Designed to run on Google Cloud Platform using startup credits, with effortless 1-click migration to Vercel/Supabase.
